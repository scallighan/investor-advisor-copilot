# investor-advisor-copilot

A sample agent that highlights several things on the Microsoft Stack

## Microsoft IQs

### Foundry IQ
Indexed data of PDFs from sharepoint featuring internal market research

### Fabric IQ
Investment holdings information

### Web IQ
Update to date information from the web, like current stock price information and external trends

### Work IQ
Integrate with the M365 suite, like email

## Agent Runtime

Whether you want something low-code, pro-code or inbetween, we have the agent runtime of your choice available

* Copilot Studio (Github Copilot Harness)
* Foundry Agent (Prompt agent service)
* Cowork (Custom skills to interact with these IQs)
